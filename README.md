# Ôn SPI

Web app luyện SPI (非言語, 英語, 構造的把握力, 組問題, 英語書き換え) với 300 câu và chế độ thi thử bấm giờ.

- Chạy hoàn toàn trên trình duyệt, không cần máy chủ.
- Cài lên điện thoại: mở trang → menu trình duyệt → "Thêm vào màn hình chính".
- Dùng được khi không có mạng sau lần mở đầu tiên.
- Kết quả luyện tập lưu trong trình duyệt của từng máy.

Thêm hoặc sửa câu hỏi: mảng `Q` trong `index.html`. Sau khi sửa, đổi `VERSION` trong `sw.js` để máy đã cài nhận bản mới.
